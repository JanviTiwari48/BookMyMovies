 BookMyMovies

A Java Console based Project-Movie Ticket Booking System built using JDBC API and MySQL also contains core Java features like Collections,Error Handling and OOPS.

 Features
- View movies
- View theaters by city
- View available shows
- Book seats
- Prevent double booking
- Store bookings in MySQL database

 Tech Stack
- Java
- JDBC
- MySQL
- IntelliJ IDEA

 Database Tables
- users
- movies
- theaters
- shows
- seat
- bookings
